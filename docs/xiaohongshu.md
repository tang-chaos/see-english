# wish coding - 看见英语

想把身边的东西，直接变成英语学习素材，于是我做了一个安卓 APP，叫「看见英语」📷

平时看到一个东西，却叫不出它的英文，这种时候就可以拿手机拍一下：看英文、看中文，词库里有的还能显示音标、听发音。遇到想记住的词，就加进生词本。识别历史会自动保存，重复的单词只记一次。

这次找了一张物品比较多的桌面照片试了试。现有 8B 模型实际返回了 7 类：相机、笔记本电脑、笔记本、手表、笔、眼镜、植物。配图里的结果来自真实离线推理，没有补上模型没说出的物品。

另外试了一张厨房照片，返回牛油果、鸡蛋、番茄等 9 类。新增的 APP 效果图用真实输出回放原生界面，已标明非真机截图。

先说我自己比较喜欢的地方 🌱
· 可以离线运行，照片在本机处理，不用填 API Key。
· 实时相机负责常见物品，拍照后的「模型识别」可以认识更多东西。
· 识别历史和生词本分开，不认识的新词也能收藏。
· 源码和安装包都开放，想研究、试用或者改一改都可以。

也有几个很实在的问题：
识别会漏、会错，复杂包装和小物体还不够稳。8B 模型约 5.45GB，APP 约 40MB，对手机资源要求挺高。手机体验里出现过单张超过 30 秒；这张示例是在电脑 CPU 上跑的，加载约 42 秒、推理约 85 秒，不能当作手机速度。

新词的音标也还没补齐，缺少时会直接提示，不让模型随便编一个。

接下来想先优化等待时间和内存占用，再继续改善细分类、小物体识别，补充离线词典和音标。

纯个人兴趣，分享一下自己做小工具的过程。现在已经能玩起来，但离成熟产品还有距离。如果你也在折腾安卓、离线模型或者英语学习工具，欢迎参考、提问题，一起慢慢改。
