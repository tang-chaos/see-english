# 一张桌面照片的真实离线识别记录

图片与许可见 [素材说明](media/README.md)。原图 1600 × 1067，缩到 672 × 448 后，使用随离线套装分发的 Qwen3-VL-8B-Instruct-MNN INT4 权重，在电脑 MNN 3.6.2 / CPU / 4 线程执行。提示词沿用当前 Android 模型识别的指令，不提供候选物品名称或参考答案。

## 模型原始词条

| 英文输出 | 中文输出 |
| --- | --- |
| Sony camera | 索尼相机 |
| laptop | 笔记本电脑 |
| notebook | 笔记本 |
| watch | 手表 |
| pen | 笔 |
| glasses | 眼镜 |
| plant | 植物 |

加载 41.86 秒，推理 85.45 秒。原始 JSON、完整提示词及运行参数见 [desk-result.json](media/desk-result.json)。加载时间与推理时间分别计算，不能只展示后者当作用户总等待时间。

照片里前后有两本笔记本，输出没有逐个计数；`plant` 只给出了粗类别，无法据此确定枝叶的种类。该样例有多个命中，不意味着复杂场景全部准确，也不说明手机一定同样输出。模型识别没有提供框，宣传配图不会画伪造的定位框。

本次是电脑真实离线推理。图片展示、结果排版或 APP 词卡回放，与手机摄像头现场识别是不同证据。此前个人体验中，手机模型识别每张超过 30 秒；尚无跨设备统一性能统计。
