请完整下载“看见英语-0.8.5-完整离线包”文件夹，不需要下载脚本、Python 或分卷合并。

文件夹内容
- see-english-0.8.5-arm64-debug.apk：最新 APP，约 40MB。
- model：完整 8B 模型，约 5.45GB，里面应有 10 个文件。
- 先看这里-安装说明.txt：同样的简短安装步骤。
- licenses：开源许可与来源。
- SHA256SUMS.txt：文件校验清单，普通用户无需手动操作。

安装只需三步
1. 在手机安装 APK。
2. 打开 APP -> 模型识别 -> 识别设置 -> 导入离线识别文件。
3. 选择下载目录中的 model 文件夹本身，保持 APP 打开并等待导入和校验完成。
之后拍照定格或从相册选照片，进入模型识别，点击“识别这张照片”即可。

已有正确模型的用户，只更新 APK 就行，不需要重复导入模型。

使用提醒
- Android 8.0+、ARM64 手机；8B 模型对内存与速度有要求，低内存设备可能无法完成识别。
- 首次导入时，下载文件与 APP 内的模型副本会同时存在，建议预留 15GB 以上可用存储。
- 导入完成后可删除网盘下载的 model 副本，不要清除 APP 数据或删除 APP 自己的模型。
- 初次安装和模型导入完成后，识别可断网使用。离线朗读需系统已安装离线英语语音。
- 当前为个人兴趣测试版，仍可能误判、漏检，模型识别比较慢；缺少音标时会明确提示。
- 覆盖更新通常保留生词本和历史，卸载或清除 APP 数据会影响它们。
